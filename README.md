# 🏦 Sistema Bancário - Projeto de Estudo

Este é um projeto simples de um sistema bancário feito em Java para praticar Programação Orientada a Objetos.

## O que o sistema faz?

- Cadastra contas (Corrente e Poupança)
- Deposita dinheiro
- Saca dinheiro com regras diferentes para cada tipo de conta
- Transfere dinheiro entre contas
- Lista todas as contas cadastradas


## Regras de negócio

- **Conta Corrente**: pode ficar com saldo negativo até o limite de R$ 500,00
- **Conta Poupança**: não pode ficar com saldo negativo
- **Transferência**: só é concluída se a conta de origem tiver saldo suficiente

## Tecnologias usadas

- Java
- ArrayList
